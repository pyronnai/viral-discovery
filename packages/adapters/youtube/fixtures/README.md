# YouTube fixtures

Synthetic responses shaped exactly like the YouTube Data API v3 reference
(`videos.list`, `videos:batchGetStats`, Google error bodies) as documented on
2026-09-28. Ids, titles, and channels are invented; no real account data and no
credentials are stored here. Replace with sanitized recordings once an API key is
available (`LIVE_API_TESTS=1`, see `src/live.test.ts`).
